# Portuguese research archive

This directory preserves the Portuguese source documents that existed before
the public Diamond documentation was reorganized in August 2026.

They contain the project's research history, detailed worklogs, early
operational drafts, and conceptual discussion. They have been retained without
translation or deletion so that design provenance remains inspectable.

For current implementation, installation, interfaces, security claims, and
roadmap, use the English documents in the parent `docs/` directory. A legacy
document is not a release guarantee and may describe superseded plans.

The suffix `.pt.md` identifies preserved Portuguese source material.
